# Architecture Review Example

Review this system design / Pull Request from an architecture perspective.

Use the `architecture-review` skill.

Assume system growth of 100x.

Requirements:

1. Evaluate bounded contexts and service boundaries.
2. Check dependency direction and coupling.
3. Identify scalability, migration, and operational risks.
4. Assign severity.
5. Provide remediation.

Output:

- Executive Summary
- Architectural Risks
- Recommendations
- Final Verdict
